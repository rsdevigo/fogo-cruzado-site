# Fogo Cruzado

Shmup vertical top-down de waves infinitas, feito em **GDevelop 5** para uma oficina de 2 horas para iniciantes.

- [GDD](GDD.md): o Game Design Document.
- [Roteiro da oficina](ROTEIRO.md): passo a passo para quem conduz a oficina.
- [Baixar o projeto inicial (.zip)](fogo-cruzado-project-limpo.zip ':ignore'): projeto GDevelop com sprites, camadas e cena de título prontos.
